# Hi, I'm Juan

I've been writing code since before I knew it had a name. Back then it was a private server for an online MMORPG running on whatever hardware I could get my hands on. Now it's microservices, cloud infrastructure, and CI/CD pipelines — but the feeling is the same: build something, break it, understand why, make it better.

Senior Agent Engineer with 13+ years of backend experience. I build software the way I now believe it should be built: I own the problem, the decisions and the quality bar, and a team of AI agents plans, implements and reviews the changes under my supervision. That background is what lets me judge what the agents produce. I work fully remote with distributed teams, and I care about the craft: clean code, good processes, reducing friction.

Always learning and trying new things to keep the pace with AI. I write about what I learn at [jdgomez.dev](https://jdgomez.dev).

## Featured

**[custom-notifier](https://github.com/jdgomez/custom-notifier)** - A native Android app (Kotlin, Jetpack Compose) that warns you before a household consumable runs out. Built entirely with agent engineering: agents wrote the code, issues, pull requests, ADRs, specs and roadmap; I approved proposals, reviewed UX and merged every PR. The process is documented in the open: session zero, way of working, 18 ADRs, OpenSpec specs, retrospectives, CI and automated releases. Currently in Play Console internal testing.

**[job-search-assistant](https://github.com/jdgomez/job-search-assistant)** - A Go CLI that scores a job posting against my profile using the Anthropic API and returns a match score, strengths, gaps and cover-letter focus points.

**[ai-world](https://github.com/jdgomez/ai-world)** - A growing, tool-agnostic collection of skills and agents for AI coding tools: project inception (session zero), Gang of Four design patterns, hooks and a usage-aware status line.
